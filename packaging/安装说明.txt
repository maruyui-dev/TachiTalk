TachiTalk 0.2.0（Windows 10/11，64位）

完整便携包：全部解压 TachiTalk.zip 后，进入 TachiTalk 文件夹运行 TachiTalk.exe。
不要在压缩包内运行，也不要只复制EXE，旁边的资源和推理环境必须保留。
GitHub分卷下载后，把全部 TachiTalk.zip.partNNN 与“Merge-TachiTalk.cmd”（合并脚本）放在同一目录，
运行脚本生成ZIP，对照SHA256SUMS.txt校验后解压。
若另行提供安装程序，默认使用 Program Files，可在安装时更改位置。
安装包包含主程序运行环境、GPT-SoVITS 推理环境、茉子语音模型、参考音频及立绘。
不需要另行安装 Python 或 GPT-SoVITS。
使用安装程序时，EXE和对应的-1.bin文件必须放在同一目录，保持配套名称。

首次启动会在后台加载本地语音模型，控制面板日志将提示就绪。
支持兼容的 NVIDIA 显卡；没有可用 CUDA 时使用 CPU，合成速度取决于电脑性能。
自带PyTorch 2.7.1 / CUDA 12.8；启动时验证GPU实际运算，失败会说明原因并使用CPU兼容模式。
使用GPU需要兼容CUDA 12.8的NVIDIA驱动。请通过NVIDIA或电脑厂商官方渠道更新驱动。
关闭控制面板会结束桌宠，并清理由本程序启动的后台语音服务。
已由用户自行启动的 GPT-SoVITS 服务会被复用，TachiTalk 退出时不会关闭它。

在线 ASR 和 LLM 需要联网，请在控制面板填写自己的 API Key。
保存设置将导出全部页面的配置和密钥，请自行保管配置文件。
运行数据、日志和导入资源位于当前用户 AppData\Local\TachiTalk；卸载时保留这些个人数据。
模型训练页面仍是开发中的界面预览，本版本不包含训练业务。

运行库包含sm_120架构支持，不要替换为旧版库。
本轮实机为Windows 11和RTX 4060 Laptop；Windows 10与RTX 50尚待目标实机验收。
仅用文字对话不需要ASR Key；录音由角色控制页开关控制。
正常关闭时自动保存界面和服务配置，启动恢复；自动配置使用Windows当前用户加密。
原创代码采用MIT；第三方依赖、角色图片、录音与模型保留各自权利，见第三方说明。
