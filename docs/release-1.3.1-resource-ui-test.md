## 行为与模块

- `app/updates/client.py`：对 Release 的 `tag_name`、`assets` 做结构验证；当前版本直接结束 main 发现，新版缺少基线附件显示 no_patch，接口未知仍尝试签名附件。网络/签名错误保留；签名清单必须与组件、当前基线和已发现 Release 匹配。API 不能授权文件安装。
- `app/ui/update_page.py`：资源页卡片和磁盘圆环。圆环表示安装盘已用容量，中心显示可用百分比；下载使用独立水平进度条。容量、语音包大小和预留均来自本机或已验签清单，不使用设计图示例数字。
- `app/ui/update_controls.py`：独立显示主程序及语音状态，显示分卷、进度、速度、剩余时间和来源；支持暂停、取消保留缓存、切源后等待旧任务结束再重试。显式暂停/取消覆盖待执行的自动切源。新检查会关闭旧更新弹窗，失效的 main 清单不能经缓存重试绕回安装。
- 新版本弹窗：展示实际当前/目标版本、发布时间、签名更新说明、包大小、“稍后提醒”和“下载并更新”。稍后/关闭保留主程序运行，下次启动仍按原检查机制检查；没有新增系统定时任务。
- `app/ui/control_panel.py`：复用现有侧栏和页面栈，资源页索引 6，导航互斥；资源页隐藏不适用的通用配置按钮。`ensure_update_controls(show=True)` 显示主面板对应页面。
- `app/ui/session_controls.py`：页面白名单新增 `deliveryPage`，支持从资源页正常保存及恢复会话。
- `app/version.py` 与安装器：本地验证包版本 1.3.1，避免修改过的二进制冒充原版 1.3.0。

## 路径与参数

- 新语音始终安装到当前主程序的 `services/gpt_sovits` 子目录，没有新增普通资源根目录选择入口。
- 旧版语音复用仍由 `settings/voice_location.json` 记录，单列兼容入口，与新增资源的安装路径分开显示。
- 下载设置保留原有来源配置与备用源禁用状态；新增 `preferred_download_source`，空值表示自动官方优先，非空表示明确选择已启用来源。禁用当前所选代理时自动回到可用来源，不会重新启用代理。
- 下载缓存仍使用现有用户数据目录 `updates/downloads`；安装器在实际下载/安装前继续检查缓存盘和安装盘空间。
