# v1.3.5 同源续传与下载提示验证版

用户在国内使用Cloudflare可开始下载，约1.8MiB/s，4%时却被自动切换来源。本轮真实日志未记录那次具体异常，未将其断定为超时。原版本Cloudflare retries=0，任何一次传输失败即可换源；本轮用真实局域HTTP断流复现并修复。

## 行为

- 收到数据即固定当前下载来源，短暂网络故障最多3次同源尝试，满足同URL/强ETag/准确Content-Range时续传；失败保留缓存供继续下载或明确手动切源。速度慢本身不触发切源，首次未收到数据且来源不可用时仍可用后备。
- 下载来源记录跨分卷、重启持久化。兼容旧部分分卷和完整.part+state；签名清单改附件URL时从零请求新URL，不把不同URL字节拼接。手动切源仍清空本任务缓存与来源锁；暂停/取消保留。
- 修复状态、来源和网络详情中长URL被Qt当作最小宽度，导致整个页面横向撑开的BUG。真实Qt复现原宽24830px、视口1088px，扩展详情案例49969px；修复后内容不超出视口。
- 点击安装/修复语音资源，在按钮下方显示“首次下载准备预计约需5分钟，完成后自动开始下载”。同时显示验签/安装空间和现有文件扫描/缓存等真实阶段及真实已用时间；数据到达前显示准备中，之后切换真实字节/速度和百分比。5分钟是预计时长，没有人为固定等待；下载不足1%明确显示<1%。

## 测试

5项原失败回归RED后GREEN（13.054秒）；复审旧完整分卷和网络详情边界RED后修复，3项边界GREEN（7.773秒）。最终全量425项429.607秒通过，最终原生安装/PYZ/ZIP/桌面/Cloudflare完整下载验SHA通过。两轮中曾有同一HTTP UI等待fixture时序失败；修正链式worker等待及QTest.qWait调度饥饿，保持原5秒上限及全部断言。连续8次相同HTTP从39.429秒降至4.593秒且全过。失败日志保留，未通过改产品或放宽断言让绿。

保留生产签名/逐卷和整包SHA校验、Cloudflare默认和静默更新、首次神态自动匹配及稳定CUDA环境。本次无完整语音下载/安装或国内用户最终安装验收，也未声称提升1.8MiB/s的带宽。

## 使用

建议新测试目录安装。若旧版任务已被自动切到其他来源，可在新版手动选择一次“Cloudflare 官方下载”后重试（按既定规则会清理当前任务旧缓存），从该来源重新开始。暂停或普通继续下载不会主动清理缓存。

GitHub正式Release与R2正式最新版本指针仍保持1.3.0；本包作为独立testing下载，不替换用户正在运行的主程序。
