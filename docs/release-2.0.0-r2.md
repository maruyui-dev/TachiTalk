版本保持2.0.0正式版，修订安装包以setup-r2命名，避免与已交付旧包混淆。本轮始终在D:\TachiTalk执行，原开发分支/脏工作区和稳定标签保留。小型快照为work/main-update-2.0.0-20261024/before；前次公开源码提交866e631亦可恢复原状态。

## 确认的问题与修复

- 魔搭主版本固定URL真实返回404，公开文件列表证实被上传成TachiTalk-v2.0.0-main-latest.json；语音清单则正常可访问。增加这个已知文件名的有限兼容和官方GitHub元数据后备。修复后源码和冻结程序均从魔搭读到2.0.0；没有上传/修改魔搭云端文件。
- 网络面板能识别系统/环境代理，而原HTTP会话trust_env=False实际没使用它。现在每次请求/重定向明确按系统代理及绕过规则路由，仍不读取netrc、不关闭TLS、不放宽资源重定向信任。
- 首次无缓存签名清单时，原检测只取清单前缀，无法得到可信分卷地址，故“未完成检测”。现在先有限读取并验签清单再做至多1KiB前缀检测，不用不可信元数据选分卷。
- 主程序更新原来被UI闸门彻底关闭。新路径由用户在UI选源、独立获取版本固定签名清单，复用现有下载校验/事务更新/重启。支持魔搭main/v版本目录和GitHub附件，新增完整主程序覆盖包构建选项。未签名/错基线/错目标拒绝，源码模式不覆盖；不伪造将来的正式签名包。
- 用户提供的PNG原样接入UI，构建据此生成多尺寸ICO；主程序/更新器EXE、安装程序、快捷方式、Qt应用/窗口统一。快捷方式使用新ICO路径和与运行进程一致的TachiTalk.Desktop标识。
- 细分11种现有情绪并提高惊讶触发条件，工具schema和追加系统规则共同提示；惊讶仍可合法返回，不做无依据文本替换。音频昵称如有“惊讶”也施加低频规则，整轮语音情绪规则不变。
- 默认茉子以日常陪伴为中心，支持倾诉、故事、讲题和咨询，移除强制游戏背景、假装看到屏幕、禁止解释和固定20～40字的限制。保留用户自定义人设，追加任务规则兼容旧短台词模板；故事/讲解等请求扩展本轮分组容量，普通聊天和明确字数偏好保留。
- 对话记忆上限从20变500，UI可选1～500，保留原5/10/20索引以恢复旧配置。最多500轮完整输入/回复用现有DPAPI和原子写入保存到user_data/memory/conversation.dat，缩小上下文只减少本轮发送量。增加状态及清空入口；关闭再尝试保存，坏文件保留并使用恢复文件，失败可诊断；清空时用修订号阻止进行中旧回复回写。额外8MB容量保护、模型上下文上限均保留。
