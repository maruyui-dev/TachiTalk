## TachiTalk 1.3.0

主程序与语音资源独立安装、独立版本管理。未安装语音时，仍可打开控制面板、设置、文字对话、立绘和气泡；在线 LLM 需要配置自己的服务。

### 下载安装

- **仅主程序**：下载 `TachiTalk-v1.3.0-main.zip`（约78MB），完整解压后运行 `TachiTalk_main_setup.exe`。EXE 和 BIN 必须在同一目录。
- **完整离线安装**：将 `TachiTalk_setup.exe` 和全部三个 `TachiTalk_setup-*.bin` 下载到同一目录，运行 EXE 并选择完整离线安装。
- **以后安装语音**：在“更新与语音资源”面板中安装。下载失败可重试、更换来源或使用签名清单与合并后的离线 ZIP 导入。

### 本版变化

- GitHub 官方下载优先，失败后自动尝试可配置的待命公共代理；可彻底禁用代理。公共代理可用性不作保证。
- 大文件在服务器正确支持 ETag / HTTP Range 时续传，暂停或取消保留已有进度。
- 安装前验证 Ed25519 清单签名、分卷及完整包 SHA-256；损坏或不适用的包拒绝安装。
- 启动后后台检查更新，显示版本、大小与更新介绍；稍后更新不会影响继续使用。
- 后续小版本使用精确基线的文件级主程序补丁，不重复下载未变化的 GPT-SoVITS 环境。
- 独立更新器等待主程序退出，备份后替换文件；失败尝试恢复，保留用户配置、导入资源与日志。

GPT-SoVITS v2ProPlus 保持 PyTorch 2.7.1 + CUDA 12.8，不需要另装 CUDA Toolkit；显卡驱动由用户安装。

### 从 v0.2.0 迁移

旧版没有自动更新器，首次请手动安装本版主程序。选择原目录，或在新版资源面板选择旧安装目录复用语音，无需重下整套环境。建议保留原配置和角色资源。

语音四个 `.partNNN` 文件由内置下载器校验、合并和安装；不要单独解压某个分卷。手动离线导入需按编号顺序合并完整 ZIP，并提供本发布的 `voice-manifest.json`。

发布前全量源码回归347项通过；无语音启动/关闭、签名校验、独立更新器与坏包拒绝已实测。此前独立语音安装、GPU推理和卸载全链已通过。本次正式完整离线安装包已编译，未再次进行完整安装；Windows10、RTX50和干净系统尚未实机验收。
