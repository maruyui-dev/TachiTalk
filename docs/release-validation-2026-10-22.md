## 完整包实测

完整包解压到新的、包含中文和空格的目录后运行冻结 EXE；使用独立用户数据目录、精简 PATH 和空闲本地端口，没有启用麦克风或调用收费 LLM/ASR。

最终冻结客户端与补齐 MSVC 的推理环境验证结果：

- UI 加载成功；回复长度范围为 `[0, 2000]`；宽窗口的预览卡片宽高比为 `0.531`。
- 私有推理环境保持 PyTorch `2.7.1+cu128` / CUDA `12.8`，实际使用 CUDA 半精度。
- 已确认推理 Python 加载的 `MSVCP140.dll` 来自包内 Python 目录，而非系统目录。
- 本地模型加载及静默预热：`35.375` 秒。
- 固定日文 `こんにちは。` 的首次 PCM 返回：`0.406` 秒；完整响应：`0.406` 秒。
- 返回非静音 PCM `70400` 字节、采样率 `32000 Hz`；自己启动的服务已退出。

该短句测试用于发行冒烟检查，不是优化前后性能对照，也没有测量实际扬声器出声。原有同文本、同参考和同采样设置的对照在 `recovery/tts_latency_2026-10-22.json`，其中首次播放指首次写设备，不是声学回环时间。
