## TachiTalk v2.0.0 正式版 · r2修订

推荐下载 **TachiTalk-v2.0.0-setup-r2.zip**。版本仍为正式版v2.0.0；r2用于区分旧安装包。

完整解压，保持TachiTalk_main_setup.exe与TachiTalk_main_setup-1.bin在同一文件夹，**右键安装程序 → 以管理员身份运行**。
已安装旧v2.0.0的用户，请正常退出后同目录覆盖安装本修订包一次；它不冒充更高版本推送。语音、导入资源和user_data保留。

### 本次改进

- 修复魔搭主版本文件名称不匹配造成404，兼容已上传名称；支持官方GitHub元数据后备。更新请求实际使用系统/环境代理，并按重定向目标执行绕过规则。
- 首次下载连接检测先取得可信签名清单再检测对应分卷；不把无缓存时的“未完成”认定为魔搭断网。
- 发现更高版本后，可在UI选择魔搭或GitHub，独立验签主程序更新，下载校验、覆盖安装并自动重启。仅版本提示或普通安装ZIP不能授权执行更新；维护者发布步骤见仓库docs/main-update-publishing.md。
- 使用新的粉色猫咪图标，统一UI、窗口、EXE、安装程序、桌面/开始菜单快捷方式与任务栏应用标识。
- 细分情绪含义，提高“惊讶”触发门槛，普通疑问、问候和轻微意外不轻易选它；真正惊讶仍保留。
- 茉子以日常陪伴为主，可听吐槽、讲故事、讲题和讨论问题，主题不限于游戏。故事和讲解可分组展开，普通闲聊保持自然简短；不编造感知或共同经历。
- 对话设置可选1～500轮上下文，本机加密保存最近最多500轮完整对话，退出再开恢复，可手动清空。减少上下文不删除其余已存记忆。

### 使用说明

Windows 10 2004及以上 / Windows 11，x64。无需另装Python；大型语音环境为可选组件，可UI安装或复用本机旧版完整环境。
AI/ASR接口由用户自行配置；本地GPT-SoVITS v2ProPlus、PyTorch2.7.1+CUDA12.8稳定栈保持。
自动配置及记忆使用当前Windows用户DPAPI。较大上下文增加请求用量，并受模型上下文上限限制；记忆另有8MB容量保护。
本次不自动迁移旧AppData；模型训练页仍为预览。语音安装退出窗口后仍可能在后台校验，请等待完成自动重启。
