## TachiTalk v2.0.0 正式版

会听、会说，也会用神态回应你的桌面伙伴。支持文字与语音交流、角色立绘、聊天气泡、AI服务配置，以及本地GPT-SoVITS语音回复。

### 下载与安装

下载 **TachiTalk-v2.0.0-setup.zip**，完整解压后保持 `TachiTalk_main_setup.exe` 与 `TachiTalk_main_setup-1.bin` 在同一文件夹。

**请右键点击 `TachiTalk_main_setup.exe`，选择“以管理员身份运行”，再按向导安装。** 不要在压缩包内直接启动，也不要只下载其中一个文件。

- Windows 10 2004及以上 / Windows 11，x64。
- 安装包内置主程序运行环境，无需另装Python。
- 主程序安装包不包含大型语音模型/runtime；可在“更新与语音资源”中安装，或复用本机旧版完整语音目录。
- 仅用文字、立绘和气泡可跳过语音安装；在线AI及ASR由用户自行配置服务与API Key。

### 本版主要改进

- 配置、导入资源、日志和缓存保存在程序旁的 `user_data`，不同安装目录独立；同目录更新保留数据，不自动读取旧AppData。
- 资源页恢复默认立即持久化，修复关闭重开读回旧映射；普通启动保留自定义。
- 完整本地语音首次识别或重新安装后开启朗读一次，之后用户主动关闭会保留；真实模型就绪仍由后台加载检查。
- 安装进行中重开会明确等待原任务，不竞争恢复或覆盖原安装结果。
- 修复图标资源漏装、下载链路检测跳滚；魔搭标识随包提供。
- 保留GitHub/魔搭选源、断点续传、来源锁、签名及完整性校验。主版本检查仅后台显示，不自动安装。

### 数据与使用说明

自动配置使用当前Windows用户DPAPI加密；换电脑/Windows用户请手动导出、加载配置，并保管可能包含API Key的导出文件。删除整个程序目录也会删除其中个人数据。

语音安装关闭主窗口后仍可能在后台解压/校验，完成后自动重启，请等待。已有完整语音可以“复用旧版语音”，避免重新下载。模型训练页仍为功能预览，不包含训练业务。
