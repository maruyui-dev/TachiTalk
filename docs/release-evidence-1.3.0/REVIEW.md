# 1.3.0 发布复核记录

本次准备公开的主程序代码及其直接调用方已按五个维度复核；这是本地发布证据，不表示GitHub附件已经上传完毕。

- 正确性：检查bootstrap→控制面板/延迟资源入口、UpdateClient→后台下载/验签→独立helper→文件事务与恢复；公开源不含私有语音目录时走文字回退。全量347项通过（403.650秒），日志 `full-tests.txt`；正式冻结核心UI/正常启动关闭、原生updater验签/坏包拒绝有相邻JSON证据。
- 可读性：签名清单、HTTP传输、Qt交互、文件事务与发布打包分别独立；暂停与HTTP续传分开，错误状态在资源面板可见。没有额外引入通用更新框架。
- 边界：main更新路径白名单排除语音与用户资产；voice更新限定推理与参考音频，精确组件版本/基线在更新器校验。追踪过portable打包调用方、Inno组件选择、旧安装目录复用及bootstrap崩溃恢复入口。
- 安全性：Ed25519固定客户端公钥、32MiB清单/100000路径上限、HTTPS官方附件/代理重定向域约束、Range/ETag/Content-Range与最终整包/分卷/文件SHA、ZIP路径及链接拒绝、独立进程等待父进程及安装锁均已检查。生产私钥在项目外，由维护者本机隐藏输入密码签名；公开提交不包含私钥、API Token、用户配置或119MB超分ZIP/训练清单。
- 性能：网络/哈希/解压/替换不在GUI线程；大清单事务避免逐文件重复写整份journal。语音文件量大导致安装/备份耗时高，已保留实际性能限制，不把断电/全硬件可用性描述为已验证。
